# Technical specs проекта Крим

## Назначение раздела

Этот раздел описывает технические решения для первой версии сайта Крим.

Technical specs нужны для того, чтобы до начала планирования и кода зафиксировать, как именно будет устроен сайт технически: архитектура, структура проекта, хранение контента, работа с фото и видео, маршруты, SEO, мультиязычность и границы будущей админки.

Technical specs не должны менять бизнес-смысл проекта, пользовательские сценарии или состав функций. Если в техническом документе появляется новая функция, сначала нужно вернуться к feature specs и описать ее там.

## Общие технические границы первой версии

Первая версия должна быть публичным сайтом без административной панели, Supabase, базы данных, форм сбора личной информации, личного кабинета, CRM-логики и онлайн-оплаты.

Контент первой версии должен быть подготовлен заранее и добавляться в проект вручную через файлы проекта. Самостоятельное управление объектами, фото, видео, отзывами и контактами владельцем компании относится к будущему этапу.

Основной технический акцент первой версии:

- Next.js;
- GitHub;
- mobile-first интерфейс;
- украинский язык по умолчанию и русский язык как вторая версия;
- цена объектов в USD;
- реальные фото и загружаемые короткие видео;
- быстрые переходы к телефону, WhatsApp и Viber;
- базовая SEO-подготовка публичных страниц.

## Правило перехода к планированию

Планирование разработки можно начинать только после того, как необходимые technical specs будут подготовлены и подтверждены пользователем.

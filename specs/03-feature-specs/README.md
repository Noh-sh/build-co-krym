# Feature specs проекта Крим

## Назначение раздела

Этот раздел содержит отдельные спецификации функций сайта.

Каждая функция должна описываться отдельно и по очереди. Новый feature spec создается только после завершения предыдущего feature spec и по указанию пользователя.

Feature specs не описывают техническую реализацию, базу данных, API, точные компоненты интерфейса или визуальные правила. Эти детали должны быть проработаны в следующих этапах спецификаций.

## Порядок проработки функций

1. Главная страница — `01-home-page.md`.
2. Проекты и дома — `02-projects-and-houses.md`.
3. Страница отдельного объекта — `03-object-page.md`.
4. Фото и видео — `04-media.md`.
5. Контакты и мессенджеры — `05-contacts-and-messengers.md`.
6. Мультиязычность — `06-multilingual.md`.
7. Отображение цены — `07-price-display.md`.
8. Отзывы и блоки доверия — `08-trust-and-reviews.md`.

Все feature specs из этого перечня на текущем этапе подготовлены.

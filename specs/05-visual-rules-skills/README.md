# Visual Rules / Skills проекта Крим

## Назначение раздела

Этот раздел описывает визуальные правила сайта Крим.

Visual Rules / Skills нужны для того, чтобы до планирования и разработки зафиксировать, как сайт должен выглядеть и ощущаться: общий стиль, композиция, mobile-first поведение, типографика, цвета, компоненты, отображение фото и видео, тон интерфейсных текстов.

Этот раздел не должен менять бизнес-логику, пользовательские сценарии, техническую архитектуру или состав функций. Если во время визуальной проработки появляется новая функция, сначала нужно вернуться к feature specs.

## Порядок проработки визуальных правил

1. Общее визуальное направление — `01-visual-direction.md`.
2. Сетка и responsive-поведение — `02-layout-and-responsive.md`.
3. Цвета и типографика — `03-colors-and-typography.md`.
4. Компоненты интерфейса — `04-components.md`.
5. Отображение фото и видео — `05-media-presentation.md`.
6. Тон текстов интерфейса — `06-content-tone.md`.

## Общая визуальная рамка

Сайт должен выглядеть спокойно, дорого, надежно и современно.

Визуальный стиль должен соответствовать небольшой строительной компании, которая работает с частными домами бизнес- и премиального уровня в Украине.

Основной визуальный акцент должен быть на реальных объектах, фото, видео, процессе строительства и доверии. Сайт не должен выглядеть как обычная строительная визитка, перегруженный каталог недвижимости или агрессивная продающая посадочная страница.

## Mobile-first правило

Визуальные правила должны разрабатываться с учетом mobile-first подхода.

Основной пользователь будет заходить с телефона и мобильного интернета, поэтому интерфейс должен быть легким, читаемым, удобным для просмотра фото и видео, с понятной навигацией и быстрыми контактами.

При этом сайт должен полноценно работать на планшетах и компьютерах.

## Правило перехода к планированию

Планирование разработки можно начинать только после того, как необходимые visual rules будут подготовлены и подтверждены пользователем.

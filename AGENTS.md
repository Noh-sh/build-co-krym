# Инструкции для агентов

## Язык проекта

Все материалы, связанные с проектом, нужно писать на русском языке кириллицей.

Пользователь может писать сообщения латиницей, но ответы, проектная документация, спецификации, тексты интерфейса, комментарии к задачам и любые заметки по проекту должны оформляться по-русски кириллицей, если пользователь явно не попросит другой язык.

## Рабочий процесс с документацией

Работа над проектом всегда выполняется в следующем порядке:

```txt
Сначала SPEC → потом PLAN → потом CODE
```

Обязательные правила:

- если функция или требование не описаны в спецификациях — не реализуем;
- если в спецификации что-то неясно — сначала уточняем;
- если новая задача противоречит спецификации — останавливаемся и устраняем противоречие;
- планирование и разработку начинаем только после завершения необходимых спецификаций.

Все спецификации нужно создавать и редактировать непосредственно в папке `specs`.

Спецификации прорабатываются строго по очереди. Новый документ можно создавать только после завершения предыдущего документа и по указанию пользователя.

Пример процесса:

- пишем глобальную спецификацию в `specs/01-global-spec.md`;
- пользователь проверяет и просит внести правки;
- после подтверждения документа переходим к следующей спецификации;
- не создаем остальные спецификации заранее.
